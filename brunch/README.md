# 브런치 발행 준비물

1. `00_첫글_교회 문의 망치는 정말 있었을까.txt` — 첫 에세이. 맨 윗줄 제목·부제는 입력칸에, 나머지를 본문에 붙인다. 마지막 `※` 줄은 지운다.
2. `소설/` — 소설 회차. `1부_*`는 1~6화, `2부_*`는 7~10화. 본문만 있고 장면 구분은 `* * *`.

## 브런치북 구성 (제안)
- 브런치북은 처음에 목차를 입력해야 하고, 연재 브런치북은 기획 의도·목차·연재 요일을 먼저 공개한다는 설명이 있다. 발간 뒤에는 목차를 더할 수 없다고 한다. 장편 전체를 한 권에 담기 어려우면 부 단위로 나눠 만든다.
  - 1부 《아흔다섯》 — 1~6화
  - 2부 《이름》 — 7~10화
- 브런치북 소개글은 `story_bible/MUNPIA_INTRO.md`의 소개글을 쓴다.
- 회차 파일을 다시 만들려면 `python scripts/export_britg.py 1 10` 후 `britg/`에서 복사한다.
